# Validation

Conduit uses table schema metadata as the authoritative validator for all incoming data mutations.

Validation occurs automatically prior to generating or executing SQL for:

- `POST /v1/<table>` (Insert)
- `PUT /v1/<table>/<id>` (Replace)
- `PATCH /v1/<table>/<id>` (Update)

---

## Validation Rules

### 1. Required Fields (`NOT NULL`)

Columns defined as `NOT NULL` without a default value must be supplied in `POST` and `PUT` request bodies.

- For `PATCH` requests, omitted fields retain their existing database values. However, explicitly passing `null` for a `NOT NULL` column triggers a validation failure.

### 2. Type Checking & Coercion

Conduit ensures incoming values are compatible with the column's underlying SQL data type:

- **Integers:** Validates whole number representation.
- **Floats / Reals:** Validates floating-point numbers.
- **Booleans:** Validates boolean types (`true`, `false`) or compatible string representations.
- **Strings / Text:** Validates string representation.
- **Timestamps:** Validates ISO-8601 formatted strings (e.g. `2026-10-08T20:30:00Z`).

### 3. Read-Only & Auto-Generated Columns

Auto-incrementing primary key columns (e.g. `id` generated by `AUTOINCREMENT` / `SERIAL` / `IDENTITY`) cannot be set manually in write operations. Supplying them in insert payloads returns an error to prevent corruption.

### 4. Extra Columns

Fields submitted in payloads that do not exist in the database table schema are rejected with a `400 Bad Request` or handled according to driver policies.

---

## Error Envelope for Validation Failures

When validation fails, Conduit halts execution immediately and returns a structured error envelope before touching the database:

### Missing Required Field Example

```http
HTTP/1.1 422 Unprocessable Entity
Content-Type: application/json

{
  "error": {
    "status": 422,
    "title": "Unprocessable Entity",
    "message": "Validation failed for table 'books'",
    "details": [
      "Column 'title' is required and cannot be null"
    ],
    "documentation": "https://conduit.untapped.tech/docs/errors/unprocessable-entity"
  }
}
```

### Invalid Column Example

```http
HTTP/1.1 400 Bad Request
Content-Type: application/json

{
  "error": {
    "status": 400,
    "title": "Bad Request",
    "message": "Invalid column provided",
    "details": [
      "Unknown column 'unknown_field' for table 'books'"
    ],
    "documentation": "https://conduit.untapped.tech/docs/errors/bad-request"
  }
}
```
